## 6. Использованные команды Git

| Команда | Назначение |
|---------|-----------|
| git clone | Клонирование удаленного репозитория |
| git checkout -b | Создание новой ветки и переключение на нее |
| git status | Проверка состояния рабочей директории |
| git add | Индексация изменений |
| git commit -m | Фиксация изменений в репозитории |
| git push | Отправка локальных коммитов на сервер |
| git pull | Получение изменений с сервера и их слияние |
| git merge | Слияние веток локально |
| git log --graph | Визуализация графа коммитов |
